## icon

An `Input` can be formatted with an `Icon`. This can be done in several ways:

*   By setting the Input's `icon` prop to the icon's name
*   By adding an `Icon` as a child element to the Input
*   By passing Icon props into the `icon` property of the Input.

  <Story of={InputVariationsStories.IconStory} />
</Canvas>
